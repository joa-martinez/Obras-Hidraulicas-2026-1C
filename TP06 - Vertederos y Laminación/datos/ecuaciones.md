# Laminación
Para realizar la laminación se adopta un delta T que de la suficiente resolución para llegar a una error de continuidad menor o igual al 2%. 

La laminación se hace con la siguiente ecuacion:
Z\index{j+1}=Z\index{j}+𝛥Z

\Delta Z = \frac{(Qe_j + Qe_{j+1})\frac{\Delta t}{2} - Qs_j\Delta t}{\left( \frac{dV_j}{dZ} + \frac{dQs_j}{dZ} \frac{\Delta t}{2} \right)}

Ya tenemos las ecuaciones de Q y V (parametrización). Las derivadas son:

\frac{dV|dZ}|=2 a Z+b
